## 2026-11-04 离线训练骨架（分支 cursor/ml-offline-train）

- 代码在 `backend/supere/train/`，入口 `python -m supere.train`。只读打开 `superE.sqlite`（`mode=ro`），不下单，不读任何密钥。
- 默认周期 12h，可切 15m / 1h；1d、1w、1M 直接拒绝（方案拍板：不做方向模型）。
- 特征只用当时已知的数据：价格和成交量读到收盘为止；资金费率要求 `funding_time < 决策时刻`；metrics 要求 `ts + 5 分钟 + 一个周期 <= 决策时刻`；NULL 保留为缺失，不做前向填充。
- 标签：triple-barrier 三分类（入场为下一根开盘价，障碍为 ±k·ATR，ATR 只用已收盘的 K 线）。同根双碰记为 ambiguous，按不利方向计，并报告占比。
- 切分：holdout（默认，最近 25% 为测试段）或 walk-forward（扩展窗口，`--mode walk_forward --folds N`）。训练样本经过 purge 和 embargo（embargo 默认等于 H）。
- 模型 LightGBM 多分类，固定轮数，不用测试段做早停。指标包括准确率、各类精确率和召回率、macro AUC、log loss、Brier，并与先验、永远做多、动量、随机基线对比。
- 回测：t+1 开盘开仓，同时只持一笔，费用两套（全吃单 0.05%×2，挂单开仓 0.02% + 吃单平仓 0.05%），滑点默认 0，资金费按持仓期间的结算计入。
- 运行结果写到 `data/logs/train-<UTC+8 时间>.log` 和同名 `.json`。
- 测试 `tests/test_train_*.py` 用 `tests/synthetic.py` 生成的小库，不需要完整库。含截断测试（第 T 行不因之后的数据而变）、未来改写测试、purge/embargo、回测记账、配置拒绝、只读连接不可写、端到端 CLI。

常用命令（在仓库根目录）：

```
python -m supere.train --data-dir D:\Tool\cg\superE\data --limit-bars 2000
python -m supere.train --data-dir D:\Tool\cg\superE\data --mode walk_forward --folds 4
python -m supere.train --print-config --interval 1h
```

本机结果（2026-11-04，家用机，库在采集器运行中读取）：样本外结果没有显示可用的边际。12h holdout 默认 300 棵树时 log loss 差于先验（1.237 对 1.099），把树减到 60 棵后 log loss 为 1.079，但回测期望仍为负。walk-forward（4 折、全历史 5053 个样本）期望也是负的。这些只是流程检查：有效独立样本远低于方案要求的 300，不能据此做策略判断。默认参数没有按样本外结果调过，如要调参，需要先把试过的次数记下来（方案 8.3）。

已知限制（代码评审后确认，暂不改）：

- 资金费在持仓时间窗口上按 K 线收盘时刻计：出场的那根 K 线内若有结算，会被计入。这对多头偏保守，对空头略偏乐观，量级约每次结算 0.01%。
- 数据缺口会按「标签窗口是否跨缺口」剔除样本。这会让样本集合取决于未来一段时间是否有缺口，只影响样本选择，不泄露特征。真实库目前缺口为 0。
