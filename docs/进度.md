## 2026-11-04 本机实测后的修正

- 指数价 K 线改为传 `pair`。标记价、溢价指数仍传 `symbol`。这三类 `limit` 不超过 1000。
- 3 日线缺口改按已落库的 `open_time` 逐步检查。2023-08 相位从「日序号 % 3 == 2」换成「% 3 == 1」之后，不再把新相位整段报成缺口。周线和月线用同一套相邻检查。
- `停止superE.bat` 不再调用 `timeout /t`。它会轮询 pid 最多 30 秒，等采集器先把 JSONL 写成 Parquet 并做完 checkpoint。验收增加 A10。
- `启动superE.bat` 用 `Start-Process` 拉起子进程，标准输出和错误分开写到 `data\logs\*.stdout.log` / `*.stderr.log`，避免 PowerShell 管道一直等着这些句柄。
- API 的 `Content-Type` 带 `charset=utf-8`。进程把 stdout/stderr 设成 UTF-8。
- 冒烟输出不再重复编号（以前是 `S1 S1 合约时间`）。

## 已知问题

- 开发环境直连 `fapi.binance.com` 返回 451。冒烟和 24 小时验收必须在走 `127.0.0.1:7890` 的 Windows 上做。
- `aggTrades` 的权重 20 没有从官方原文核实。配置项 `rate_limit.agg_trade_weight` 可以改。
- 家用机时钟曾经慢大约 6 秒。程序会记偏移并在绝对值超过 2 秒时写 `CLOCK_SKEW`，但不会自己启动 w32time。
- 共享代理出口的权重响应头包含别人的流量。验收不拿它做失败条件。
- 强平是抽样。异动里的强平金额是下限。
- 盘口按 100ms 全量保存，压缩后大约每天几十 MB。磁盘低于 50GB / 20GB 会记事件，没有自动删数据。
- 标记价、指数价、溢价指数的实时 K 线靠 REST 轮询已收盘的棒，没有单独的 K 线 WebSocket。
- 空库启动不会自动拉全历史，避免打满限速。需要先跑 `supere backfill`。
